# 实现与验收

## 原项目检查

原生 JavaScript ES modules，Three.js 0.187.0。入口 `dist/app.js`。GLTFLoader 加载单个 `room-v9.glb`，沿用 Meshopt、GPU instancing、WebP 和导出材质。RoomEnvironment / PMREM 提供环境反射；程序材质在既有导出流程中烘焙为纹理。未引入 React、Draco、KTX2 或新房间模型。

初始相机改为第三视角，围绕房间中心 `(1.75, 0.95, -2.15)` 自由旋转及缩放，关闭平移以保持居中。这依据最新用户指令替代旧提示词的固定门口相机要求。

## 三种表现

BASIC 是纯黑背景与三盏简化几何灯。DETAIL 是同一原模型的法线/深度边缘线稿，由三盏灯的世界空间区域遮罩逐渐显现。COLOR 使用保留的原材质纹理，只在已阅读故事物品附近显示，并以柔和不规则边缘衔接。三个真实灯位各一盏 Three.js 点光，暖黄开启后平滑增加强度；少量灯泡光晕仅用于在黑白环境中辨识点灯状态。

四面墙分别根据相机相对房间的朝向计算渐隐权重，不使用“仅选最大一面墙”的判断。墙材质在世界空间逐片元控制透明度；靠地面约 4–43cm 形成连续过渡，转角可同时隐藏多面墙。远侧墙保留，地板不变。高柜、床头板、窗帘、散热器、挂画等前景遮挡物使用漫画网点透视，随视角变化，远侧恢复实体。屋顶作为第三人称剖切层隐藏。

线稿用共享 color / normal-depth Render Target 和一个屏幕合成 Shader；故事开启时再用共用合成目标做轻微背景模糊。故事物品和正文固定两栏，正文独立滚动并按是否存在溢出内容显示上下 60px 渐隐。手机改为物品上、正文下。全部正文来自用户给定文本。

最新指令已经删除鼠标透视和拖尾：不保留轨迹数组、移动揭露 Shader 或 hover 区域揭露。只在灯/已解锁故事物品上改变鼠标外观，其它位置保持系统鼠标。

## 前景漫画网点（2026-11-12）

在原材质和法线 / 深度通道中加入一致的 45° Ben-Day 圆点筛网，间距 7 CSS px。近侧遮挡物最稀疏时仅保留约 6% 点阵覆盖；孔隙直接丢弃片元和深度，因此能看到真实的后方模型，多层前景也不会叠成实心灰面。点的半径按视角连续变化，转至远侧或俯视时恢复原样，底部保留渐变过渡。合成通道抑制点阵边缘的重复描边，避免每个点被线稿膨胀。

使用八组经源场景测量的空间范围处理合并后的 Mesh，地板不参与。六个交互对象（left、desk、bedside、cello、boots、laptop）有优先排除范围，灯具和故事物品不会被点阵化。鼠标拾取仅与已解锁交互对象相交，任何前景家具均不阻挡点击；橙圈仍只出现在交互物品上。原模型及故事展示几何不变。

专项验收：从高柜背面直接点击画布内三盏灯和三个故事（测试中关闭 HTML 热区，验证真实画布拾取），桌面和手机尺寸均成功；东 / 西 / 北三个遮挡角度进行开启 / 关闭截图对照；多次变化视角与网点状态后几何体数仍为 282，无浏览器错误。手机尺寸在桌面 Chrome 中模拟，并非实体设备测试。

## 状态与性能

集中维护 illuminatedLights / exploredObjects / hoveredObject / activeStory / helpUnlocked / pointerMode。版本化本地存储安全处理坏数据、不可用存储和一次性 reset 参数。只有打开故事才计入阅读进度。进度仅属于当前设备。

整个页面共用一个 requestAnimationFrame 循环和一个 WebGLRenderer，包括故事展示。GLB 单次加载；故事展示复用 geometry attribute 和纹理；未探索颜色前跳过彩色 pass，完全暗场时跳过房间 pass。固定大小的 Render Target 在 resize 时复用/调整尺寸，隐藏页面暂停渲染，静止暗场按需渲染。像素比上限桌面 1.5 / 手机 1.25；手机关闭太阳阴影，减少采样，动画限速。支持 reduced-motion；关闭/反复打开故事不会新增几何体或纹理。

## 验证

Playwright 在本机 Chrome 完成 1440×1000 桌面与 390×844 触摸视口测试：

- 实际拖动改变第三人称视角，四个角度同时隐藏对应两面墙。
- 锁定物品不能打开，三盏灯与三个故事的解锁关系正确。
- 真实按钮点击、帮助解锁、标题、完整正文、滚动渐隐、Escape 关闭通过。
- 正常鼠标 / 物品橙圈切换通过；无移动透视 API / 拖尾。
- 页面刷新恢复三个故事；损坏存储安全重置；reset 删除一次且保留其它参数。
- 故事反复开启关闭，几何体及纹理计数稳定。
- 初始会话 GLB 请求一次；无未处理异常或浏览器错误。
- 无 WebGL 时显示预览与可阅读故事入口。

GPU 工作量来自原有高细节场景，低端移动设备的帧率不能保证达到 60 FPS；测试是桌面 Chrome 的触摸视口模拟，尚未覆盖所有实体手机及 Safari。黑白线稿是深度/法线描边，并非逐笔绘制的矢量图。Blender 与 WebGL 的材质、阴影仍存在渲染器差异。
